# SPEC.md — спецификация sub-tracker

Веб-приложение, в котором пользователь ведёт список своих подписок (стриминги, софт, облака и т.д.) и видит, сколько и когда он за них платит.

## Фичи

### 1. Личный кабинет

- [x] Гость видит стартовую страницу с кнопками **«Войти»** и **«Зарегистрироваться»** (вход и регистрация — раздел 5).
- [x] Страницы кабинета (дашборд, подписки, профиль) недоступны гостю — редирект на страницу входа.
- [x] В шапке кабинета отображается имя текущего пользователя и кнопка **«Выйти»**.
- [x] «Выйти» завершает сессию и возвращает на стартовую страницу.
- [x] Страница профиля: имя и email пользователя (только просмотр) и выбор основной валюты (см. раздел 4).

### 2. Управление подписками

- [x] Добавление подписки через форму:
  - название сервиса — обязательно;
  - стоимость — обязательно, > 0;
  - валюта — из фиксированного списка (см. раздел 4), по умолчанию — основная валюта пользователя;
  - период оплаты — ежемесячно / ежегодно;
  - дата начала подписки — обязательно;
  - категория — из фиксированного списка (видео, музыка, софт, облако, игры, обучение, другое).
- [x] Валидация формы с понятными сообщениями об ошибках (на клиенте и на сервере).
- [x] Список подписок пользователя: название, категория, стоимость в валюте подписки + период, дата следующего списания.
- [x] Редактирование подписки.
- [x] Удаление подписки (с подтверждением).
- [x] Пользователь видит и меняет **только свои** подписки.
- [x] Пустое состояние списка с призывом добавить первую подписку.

### 3. Дашборд

- [x] Сводка: количество активных подписок, суммарные траты в месяц и в год (годовые подписки приводятся к месяцу как `цена / 12`).
- [x] **Траты по месяцам** — график фактических списаний за последние 12 месяцев (годовая подписка учитывается в месяце списания).
- [x] **Траты по категориям** — распределение месячной нагрузки по категориям (график/диаграмма + суммы).
- [x] **Напоминание о продлении** — блок «Скоро продление»: подписки, у которых следующее списание в ближайшие 7 дней, отсортированные по дате.
- [x] Пустое состояние дашборда, если подписок нет.

### 4. Мультивалютность

- [x] Валюты подписок: рубль (RUB), доллар США (USD), евро (EUR), фунт стерлингов (GBP), юань (CNY), тенге (KZT), турецкая лира (TRY).
- [x] У каждой подписки своя валюта; в списке и в блоке «Скоро продление» цена показывается в валюте подписки.
- [x] **Основная валюта пользователя** (по умолчанию ₽) выбирается на странице профиля. Итоги дашборда (сводка, траты по месяцам и категориям, сумма «Скоро продление») пересчитываются в неё.
- [x] Пересчёт — по текущему курсу ЦБ РФ (источник — cbr-xml-daily.ru), на дашборде указана дата курса. Если курсы недоступны, используется последний сохранённый курс; если курсов нет совсем — подписки в других валютах не входят в итоги, и дашборд об этом предупреждает.

### 5. Авторизация (Neon Auth)

- [x] Регистрация и вход по email и паролю; вход через Google.
- [x] Обязательное подтверждение email: без подтверждения кабинет недоступен.
- [x] Выход завершает сессию и возвращает на стартовую страницу.
- [x] Кабинет и данные доступны только вошедшему пользователю; каждый видит только свои подписки.
- [x] Стартовая страница: кнопки «Войти» и «Зарегистрироваться» вместо демо-входа.
- [x] Демо-аккаунт удаляется вместе с его подписками.

## Вне рамок (сейчас делать нельзя)

- ❌ Исторические курсы: траты прошлых месяцев пересчитываются по текущему курсу, а не по курсу на дату списания.
- ❌ Ручной ввод и редактирование курсов валют.

## Критерии готовности MVP

- [x] Все фичи из раздела «Фичи» реализованы и работают.
- [x] Основная бизнес-логика покрыта unit-тестами (расчёт следующей даты списания, агрегации по месяцам и категориям, валидация подписки), все тесты зелёные (`pnpm test`).
- [x] Приложение собирается без ошибок (`pnpm build`), `pnpm lint` проходит без ошибок.
